# brunohlopez.github.io

Source for my personal portfolio site, published with GitHub Pages at <https://brunohlopez.github.io>.

It is a plain static site with no build step:

```
index.html   # page content
style.css    # styling
script.js    # hero Sentinel-2 map, scroll effects, interactive chart, nav highlighting
images/      # images used on the page
Resume/      # downloadable resume (PDF)
```

To preview locally, serve the folder with any static server, for example `python -m http.server 8000`, and open <http://localhost:8000>.

The code for the projects featured on the site lives in [machineLearning](https://github.com/brunohlopez/machineLearning).
